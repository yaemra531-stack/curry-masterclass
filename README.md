## 🚀 最新升级功能

### 1. ⚡️ 赛前 20 分钟控球爆发专项（Pre-Game 20-Min Focus Drill）
- **科学五阶唤醒流程**：
  1. `00:00 - 03:00 (3分钟)`：超低空指尖控球（10-15cm 极限激活神经末梢）
  2. `03:00 - 07:00 (4分钟)`：重力下砸与同侧口袋悬停（Pocket Float 滞空 0.3s）
  3. `07:00 - 11:00 (4分钟)`：双脚宽坠步与大跨度变向（Drop Stance & Crossover）
  4. `11:00 - 15:00 (4分钟)`：招牌实战三连招（胯下刺探 → 背后贴臀拉回 → 抬头犹豫步 Hezi）
  5. `15:00 - 18:00 (3分钟)`：爆发推球冲刺与贴地急停拉回（创造 1.2m 空间）
  6. `18:00 - 20:00 (2分钟)`：盲视超负荷与手感暴燃（剥离视觉，带满手感上场）
- **交互控制台**：内置 20:00 倒计时、阶段进度环、阶段切换提示音（Web Audio 合成）、一键练习单个动作与今日赛前手感打卡评星（⭐️ 1-5星）。

### 2. 🎨 全套动作高清矢量图解（SVG Diagrams）
- 涵盖 17 门完整课程 + 6 个专项热身动作，内置 23 张高对比度技术力学图解。
- 标明重心下沉幅度、手掌指腹触球区、同侧脚膝肘腕 4 点垂直对齐力线与篮球反弹轨迹。
- 配套**核心体感口诀标签（Cues）**与**避坑指南（Don't）**。
- 支持点击任意图解打开**全屏高清灯箱（Lightbox）**放大查看。

### 3. 📷 动作截图与示范图粘贴上传（Cmd+V 即贴即存）
- 每节课程下方支持直接按快捷键 `Cmd+V` / `Ctrl+V` 粘贴截图，或点击选择本地图片/动图。
- 自动轻量压缩并持久化存储在浏览器本地（离线依然可用），方便回看自己的实拍对比。
