# 库里大师课 · 篮球训练学习系统 (Curry Masterclass)

> 斯蒂芬·库里（Stephen Curry）大师课系统化训练与要点复盘平台。涵盖从投篮力学、脚步移动、运球爆发到实战决策的全套课程知识库与实操训练计划。

🌐 **在线体验地址**：[https://yaemra531-stack.github.io/curry-masterclass/](https://yaemra531-stack.github.io/curry-masterclass/)

---

## ✨ 核心特性

- **完整课程模块体系**：拆解库里投篮机制、持球爆发、掩护利用、抛投终结等关键技能。
- **结构化知识卡片**：逐课精讲、动作要点、易犯错误与自我校准清单。
- **实战需求索引**：按实战场景（单打、接球投篮、挡拆处理）快速定位训练方案。
- **训练计划与笔记**：内置实操训练周期表与个人复盘笔记。
- **现代化极简设计**：自适应深色 / 浅色模式，支持移动端随时随地查阅。

---

## 🛠 本地运行

纯原生前端单页架构，无任何外部构建依赖：

```bash
# 克隆仓库
git clone https://github.com/yaemra531-stack/curry-masterclass.git
cd curry-masterclass

# 直接在浏览器打开 index.html 即可
open index.html
```
